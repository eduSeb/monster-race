# Monster Race

Un jeu éducatif pour apprendre les chiffres aux enfants en s'amusant avec des monstres.

## Comment jouer

1. Lancez `lancer_le_jeu.bat` (nécessite Node.js).
2. Ouvrez votre navigateur sur `http://localhost:8765`.
3. Choisissez votre monstre et le niveau.
4. Prononcez les chiffres à voix haute pour faire avancer votre monstre !
